# 01 - Basics

This module introduces the fundamental building blocks of LangChain.

## Files

| File | Description |
|------|-------------|
| 01_llm.py | Initialize a ChatGroq model and generate a response. |
| 02_chat_models.py | Understanding chat models. |
| 03_ai_message.py | Working with AIMessage objects. |
| 04_system_human_messages.py | Using SystemMessage and HumanMessage. |
| 05_chat_history.py | Maintaining conversation history manually. |

## Learning Outcome

After completing this module, you will understand:

- How to initialize an LLM
- How `invoke()` works
- What `AIMessage` is
- How chat messages are structured
- How basic conversation history works
